# 04 · 入门阶段

这是你真正"动手"的开始。目标:从完全不会,到能完整弹出一首简单的歌。
按顺序学完这个模块,你就跨过了最难的"从 0 到 1"。

## 本模块内容(建议按顺序学)

1. [持琴与姿势.md](./持琴与姿势.md) —— 坐姿、抱琴、左右手姿势(基础中的基础)
2. [调音入门.md](./调音入门.md) —— 标准调弦、怎么用调音器、各弦音名
3. [看懂和弦图与TAB谱.md](./看懂和弦图与TAB谱.md) —— 三种谱的读法
4. [第一批开放和弦.md](./第一批开放和弦.md) —— 8 个必学和弦 + 指法
5. [换和弦练习.md](./换和弦练习.md) —— 让换和弦不再卡顿
6. [第一首曲子.md](./第一首曲子.md) —— 把学到的串成一首歌

## 入门阶段里程碑 ✅

- [ ] 坐姿和持琴自然不别扭
- [ ] 能自己把吉他调准
- [ ] 看懂和弦图,能按出 C、G、D、Em、Am
- [ ] 能在两个和弦间较顺畅切换
- [ ] 能用一种扫弦型完整弹出一首简单的歌

## 给入门者的话

- 前两周手指会痛、按弦会闷响,这是**所有人**都经历的,坚持就好。
- 不要追求快,把每个动作做对。
- 每天 15–30 分钟,比一周一次强太多。
- 卡住很正常,随时回来查这些笔记,或让我帮你拆解。
