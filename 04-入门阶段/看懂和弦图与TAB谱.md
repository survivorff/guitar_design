# 📖 看懂和弦图与 TAB 谱

吉他有三种常见记谱:**和弦图、TAB(六线谱)、五线谱**。
入门阶段重点掌握前两种,五线谱在走古典路线时再深入。

---

## 一、和弦图(Chord Diagram)

和弦图告诉你"一个和弦怎么按"。它是一张**竖着画的指板示意图**。

```
      C 和弦
   E A D G B E   ← 6到1弦(从左到右)
 ┌─────────────┐
 │ X     0   0 │  ← 顶部:X=不弹此弦, 0=空弦弹
 ├─┬─┬─┬─┬─┬─┬─┤
 │ │ │ │ │①│ │  第1品   ①=食指
 ├─┼─┼─┼─┼─┼─┼─┤
 │ │②│ │ │ │ │  第2品   ②=中指
 ├─┼─┼─┼─┼─┼─┼─┤
 │③│ │ │ │ │ │  第3品   ③=无名指
 └─┴─┴─┴─┴─┴─┴─┘
```

**怎么读**:
- **竖线 = 6 根弦**。注意方向:最左是 6 弦(最粗),最右是 1 弦(最细)。
- **横线 = 品丝**。最上面那条粗线代表**弦枕(nut)**,往下是第 1、2、3…品。
- **圆点 = 手指按的位置**,点里的数字代表用**哪根手指**:
  - 1=食指, 2=中指, 3=无名指, 4=小指。
- **顶部符号**:
  - `O` 或 `0` = 这根弦**空弦弹响**。
  - `X` = 这根弦**不弹/闷掉**。
- **横跨多弦的弧线/粗杠** = **横按(barre)**,用一根手指压住多根弦。

> 上面的 C 和弦:食指按 2 弦 1 品,中指按 4 弦 2 品,无名指按 5 弦 3 品;1、3 弦空弦;6 弦不弹。

## 二、TAB 谱 / 六线谱(Tablature)

TAB 是吉他最常用的记谱,直接告诉你"哪根弦、第几品"。它是**横着的 6 条线**。

```
e|---0---1---3---|   ← 最上面是 1 弦(最细/最高)
B|---1-----------|
G|---0-----------|
D|---2-----------|
A|---3-----------|
E|---------------|   ← 最下面是 6 弦(最粗/最低)
```

**怎么读**:
- **6 条横线 = 6 根弦**。⚠️ 注意:**最上面一条是 1 弦(最高音)**,最下面是 6 弦(最低音)。和弦图方向不同,别搞混。
- **线上的数字 = 第几品**。`0` = 空弦,`3` = 第 3 品。
- **从左往右** = 时间先后,挨个弹。
- **同一竖列上的多个数字** = 同时弹(即一个和弦)。
- 上例最左列同时弹各弦 → 就是一个 C 和弦的分解起始。

**TAB 上的技巧符号(常见)**
| 符号 | 含义 |
|------|------|
| `h` | hammer-on 击弦(如 `5h7`) |
| `p` | pull-off 勾弦(如 `7p5`) |
| `/` | slide up 上滑音 |
| `\` | slide down 下滑音 |
| `b` | bend 推弦(如 `7b9`) |
| `~` | vibrato 揉弦 |
| `x` | 闷音/打弦 |
| `()` | 泛音或幽灵音 |

> TAB 的缺点:**不直接显示节奏(时值)**。所以常需配合听原曲来掌握节奏。

## 三、五线谱(Standard Notation)

- 通用音乐记谱,精确表示音高**和节奏时值**。
- 吉他用**高音谱号**,实际发音比记谱低八度。
- 古典吉他体系重视五线谱;流行/摇滚常只用 TAB。
- **建议**:走古典/严肃音乐路线一定要学五线谱;弹唱玩票可以先靠和弦图+TAB,但懂五线谱永远是加分项。
- 五线谱详解放在 `05-乐理基础`,这里先知道它的存在和价值即可。

## 四、节奏记号(配合扫弦)

弹唱谱常在和弦上方标扫弦方向:
- **↓** = 下扫(从粗弦扫到细弦)
- **↑** = 上扫(从细弦扫到粗弦)

例如:`↓ ↓ ↑ ↑ ↓ ↑` 是一个非常常见的扫弦型(见 `06-基础技巧`)。
