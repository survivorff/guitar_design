# 🗺️ 吉他学习完整路线图

这张路线图把吉他学习分为五个阶段。每个阶段都给出:**目标、核心能力、关键知识点、里程碑(达成标志)、预估周期**。
周期因人而异,这里以"每天有效练习 30–60 分钟"为基准估算,仅供参考。

---

## 阶段总览

```
入门 ──→ 进阶 ──→ 精通 ──→ 大师 ──→ 艺术家
Beginner  Intermediate  Advanced  Master   Artist
0–3月     3–12月        1–3年      3–6年     终生
```

成长不是线性的,更像螺旋:你会在更高阶段反复回到基础,带着新的理解重新打磨它。

---

## 🟢 阶段一:入门(Beginner)

**目标**:把吉他变成"不陌生的东西",能完整弹出几首简单的歌。

**核心能力**
- 正确的坐姿、持琴、左右手姿势
- 给吉他调音(借助调音器/App)
- 掌握 8 个开放和弦:C、G、D、Em、Am、E、A、Dm
- 顺畅地在常用和弦间切换
- 基本扫弦节奏(下扫、下上扫)
- 看懂和弦图(chord diagram)与六线谱(TAB)

**关键知识点**
- 吉他各部位名称
- 弦的编号与音名(6→1 弦:E A D G B E)
- 节拍、4/4 拍的概念

**里程碑** ✅
- [ ] 能不看手、凭肌肉记忆按出 C 和 G
- [ ] 能用一种扫弦型完整弹唱/伴奏一首简单歌曲
- [ ] 能自己把跑音的吉他调准

**预估周期**:1–3 个月
**对应模块**:`04-入门阶段`、`06-基础技巧`(前半)

---

## 🔵 阶段二:进阶(Intermediate)

**目标**:摆脱"只会几首歌",开始理解音乐是怎么运作的,手上技术成型。

**核心能力**
- 大横按(F、B 等封闭和弦)
- 多种扫弦节奏型与切音、闷音(palm mute)
- 基础指弹(Travis picking、分解和弦)
- 五声音阶(pentatonic)的五个把位
- 基础推弦、击弦勾弦(hammer-on / pull-off)、滑音
- 用节拍器稳定地控制速度

**关键知识点**
- 大小调音阶构成
- 和弦的构成(三和弦、七和弦)
- 调内和弦(级数 / 罗马数字:I–IV–V 等)
- 常见和弦进行(1-5-6-4 等)

**里程碑** ✅
- [ ] 能干净地按响 F 大横按和弦
- [ ] 能用五声音阶在一段伴奏上即兴 solo
- [ ] 能听出一首简单流行歌的和弦走向并扒下来
- [ ] 节拍器 80–120 BPM 内稳定演奏

**预估周期**:3–12 个月
**对应模块**:`05-乐理基础`、`06-基础技巧`、`07-进阶技巧`(前半)

---

## 🟣 阶段三:精通(Advanced)

**目标**:技术体系化,乐理融会贯通,能在多种风格里自如表达。

**核心能力**
- 全指板音名/音阶/和弦视野(fretboard mastery)
- 七声调式(modes)的应用
- 即兴中能主动选择音阶、和弦内音、经过音
- 进阶技巧:扫拨(sweep)、点弦(tapping)、人工泛音、混合拨弦
- 多风格基本功:布鲁斯、摇滚、爵士、民谣指弹、古典

**关键知识点**
- 调式(Ionian–Locrian)与其色彩
- 二级五级一级(ii-V-I)、副属和弦、转调
- 和声功能(Tonic/Subdominant/Dominant)
- CAGED 系统与三连音/音组(licks)

**里程碑** ✅
- [ ] 闭眼能说出指板任意位置的音名
- [ ] 能跟一个不熟悉的和弦进行做出有逻辑的即兴
- [ ] 能演奏至少 3 种风格的代表性曲目
- [ ] 能为一段旋律配和弦

**预估周期**:1–3 年
**对应模块**:`05-乐理基础`(后半)、`07-进阶技巧`、`08-精通阶段`

---

## 🟠 阶段四:大师(Master)

**目标**:拥有自己的技术语言和声音,能编曲、能教学、能解决任何技术问题。

**核心能力**
- 深度和声:扩展和弦、变化和弦、再和声化(reharmonization)
- 编曲与配器思维,多声部写作
- 精细的音色控制(触弦、动态、音箱/效果器调校)
- 高度个人化的演奏风格与"手感签名"

**关键知识点**
- 高级爵士和声、调式交替、负和声等概念
- 对位与声部进行
- 录音室与现场的音色工程

**里程碑** ✅
- [ ] 能把一首歌重新编曲成完全不同的风格
- [ ] 别人能从几个音里听出"这是你弹的"
- [ ] 能系统地把你的方法讲给别人听

**预估周期**:3–6 年及以上
**对应模块**:`09-大师阶段`

---

## 🔴 阶段五:艺术家(Artist)

**目标**:超越技术,用吉他作为表达自我与连接他人的媒介。

**核心能力**
- 把情感、故事、审美注入演奏
- 原创与作曲
- 在不完美中表达真实(技术服务于表达)
- 舞台掌控与录音作品创作

**关键知识点**
- 音乐美学与个人风格的形成
- 即兴中的"叙事"与张力管理
- 与其他音乐家的协作与对话

**里程碑** ✅
- [ ] 有自己的原创作品
- [ ] 演奏能让听众产生情绪共鸣,而非只惊叹技巧
- [ ] 找到了"为什么而弹"的答案

**预估周期**:终生
**对应模块**:`10-艺术与表达`

## 📌 能力坐标自测

给自己在每个维度打分(1–10),定期回看进步:

| 维度 | 说明 |
|------|------|
| 手指机能 | 速度、力量、独立性、耐力 |
| 节奏感 | 稳定度、律动、复杂节奏处理 |
| 乐理理解 | 音阶、和声、调式的掌握 |
| 听力 | 扒谱、辨音、辨和弦 |
| 即兴能力 | 在伴奏上自由表达 |
| 音色控制 | 动态、触弦、设备调校 |
| 曲目量 | 能完整演奏的曲子数量 |
| 表达力 | 情感与音乐性 |
