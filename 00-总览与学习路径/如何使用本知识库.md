# 📘 如何使用本知识库

## 三种使用方式

### 1. 顺序学习(推荐零基础)
按目录编号 `00 → 01 → ... → 13` 顺序推进。但不必读完一个模块再开始下一个——
基础技巧和乐理是**交替进行**的:学一点理论,马上在琴上练出来。

推荐的零基础起步顺序:
```
00 总览  →  01 历史(快速浏览,建立兴趣)  →  04 入门阶段(动手)
        →  06 基础技巧 + 05 乐理基础(交替)  →  11 练习计划
```

### 2. 按需查阅(已有基础)
把它当字典。想练推弦就去 `07-进阶技巧`,想搞懂调式就去 `05-乐理基础`。

### 3. 跟着练习计划走
直接用 `11-练习计划与方法` 里的模板,每天照着练,卡住了再回来查对应知识点。

## 每个模块的结构约定

- 每个模块文件夹里都有一个 `README.md` 作为该模块索引。
- 知识点文件命名尽量用中文,见名知意。
- 练习项会用 ✅ 复选框列出,方便你勾选打卡。

---

## 配合工具

学习吉他强烈建议配合这些工具(详见 `03-装备与配置` 与 `13-资源与社区`):

- **调音器**:手机 App(GuitarTuna 等)或夹式调音器
- **节拍器**:App 或实体,练节奏的命根子
- **录音**:手机录下自己弹的,回听是进步最快的方法之一
- **慢放工具**:能变速不变调的播放器,用来扒谱

---

## 关于"慢慢完善"

这个库是活的。建议:

- 每次学到新东西,在对应文件里追加你自己的笔记(可以用 `> 我的笔记:` 开头)。
- 遇到弹不好的地方,记录下来,形成你的"问题清单"。
- 找到好的曲子/教程,丢进 `12-曲目库` 或 `13-资源与社区`。

> 你可以随时让我帮你扩写任何一个模块、添加新内容、或者根据你的进度调整计划。
