## 核心理念

1. **慢就是快**:把动作做对再做快,错误动作练一万遍只会更难改。
2. **每天少量胜过周末突击**:每天 20–30 分钟远胜一周一次 3 小时。
3. **耳朵先于手指**:听不出来的东西,弹不准。多听多模仿。
4. **乐理是地图不是枷锁**:懂乐理是为了更自由,不是为了考试。
5. **享受当下**:技术是工具,音乐是目的,享受是意义。
