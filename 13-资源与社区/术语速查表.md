# 📚 术语速查表

吉他和乐理常见术语中英对照与简短解释。看教程、查谱时遇到不懂的词,来这里查。
(按主题分组,持续补充。)

---

## 吉他构造

| 术语 | 英文 | 含义 |
|------|------|------|
| 琴头 | Headstock | 装弦钮的顶端 |
| 琴颈 | Neck | 连接琴头与琴身,背面是手指支撑处 |
| 指板 | Fretboard / Fingerboard | 按弦的表面 |
| 品丝 | Fret | 指板上的金属条 |
| 品(格) | Fret position | 两品丝间的区域 |
| 弦枕(上枕) | Nut | 琴头侧的卡弦件 |
| 下枕 | Saddle | 琴桥上决定弦高/振动起点的条 |
| 琴桥 | Bridge | 固定弦下端 |
| 拾音器 | Pickup | 电吉他把振动转电信号的部件 |
| 钢筋/调节杆 | Truss rod | 琴颈内调弯曲的钢杆 |
| 弦距 | Action | 弦到指板的高度 |
| 音准 | Intonation | 全指板音高的准确度 |

## 记谱与符号

| 术语 | 英文 | 含义 |
|------|------|------|
| 六线谱 | TAB / Tablature | 标弦与品的吉他谱 |
| 五线谱 | Standard notation | 通用记谱 |
| 和弦图 | Chord diagram | 显示和弦指法的图 |
| 拍号 | Time signature | 如 4/4,定义每小节拍数 |
| 变调夹 | Capo | 夹住某品升高整体调 |
| 升号 | Sharp (#) | 升高半音 |
| 降号 | Flat (b) | 降低半音 |

## 技巧

| 术语 | 英文 | 含义 |
|------|------|------|
| 击弦 | Hammer-on (h) | 左手砸品发声 |
| 勾弦 | Pull-off (p) | 左手勾离弦发声 |
| 滑音 | Slide (/ \) | 按弦滑动改变音高 |
| 推弦 | Bend (b) | 推弦升高音高 |
| 揉弦 | Vibrato (~) | 音高规律小幅波动 |
| 闷音(手掌) | Palm mute (P.M.) | 右手掌闷弦 |
| 切音 | Staccato | 音符短促止音 |
| 扫弦 | Strumming | 扫过多根弦 |
| 指弹 | Fingerstyle | 用手指拨弦 |
| 交替拨弦 | Alternate picking | 上下拨交替 |
| 经济拨弦 | Economy picking | 换弦顺势同向拨 |
| 扫拨 | Sweep picking | 一方向连续扫多弦弹琶音 |
| 点弦 | Tapping (t) | 右手点品发声 |
| 泛音 | Harmonics | 触弦节点发出的清亮音 |
| 强力和弦 | Power chord | 只含根音+五音的和弦 |
| 横按 | Barre | 一指压多根弦 |
| 琶音 | Arpeggio | 和弦的音逐个弹出 |
| 轮指 | Tremolo | 快速反复拨同一音 |

## 乐理

| 术语 | 英文 | 含义 |
|------|------|------|
| 半音 | Half step / Semitone | 最小音程,吉他一品 |
| 全音 | Whole step / Tone | 两个半音 |
| 音程 | Interval | 两音间距离 |
| 音阶 | Scale | 按音程排列的一串音 |
| 大调 | Major scale | 全全半全全全半 |
| 小调 | Minor scale | 自然小调:全半全全半全全 |
| 五声音阶 | Pentatonic | 五个音的音阶 |
| 调式 | Mode | 同音组不同中心(多利亚等) |
| 和弦 | Chord | 多音同时发声 |
| 三和弦 | Triad | 根+三+五 |
| 七和弦 | 7th chord | 三和弦加七度 |
| 转位 | Inversion | 换最低音的和弦排列 |
| 级数 | Scale degree / Roman numeral | 和弦在调内的位置(I-vii) |
| 和声进行 | Chord progression | 和弦的连接序列 |
| 属和弦 | Dominant (V) | 制造解决张力的和弦 |
| 主和弦 | Tonic (I) | 调的"家" |
| 下属和弦 | Subdominant (IV) | 铺垫功能 |
| 转调 | Modulation | 转换到另一个调 |
| 副属和弦 | Secondary dominant | 临时属和弦增加牵引 |
| 关系大小调 | Relative major/minor | 共用同组音的大调与小调 |

## 演奏 / 录音 / 设备

| 术语 | 英文 | 含义 |
|------|------|------|
| 节拍器 | Metronome | 给固定节拍的工具 |
| 伴奏音轨 | Backing track | 用于即兴练习的伴奏 |
| 即兴 | Improvisation | 即时创作演奏 |
| 扒谱 | Transcription | 用耳朵把音乐听写下来 |
| 律动 | Groove | 节奏的"感觉" |
| 摇摆 | Swing | 成对八分弹成长短 |
| 平直 | Straight | 八分等长 |
| 动态 | Dynamics | 音量强弱变化 |
| 失真/过载 | Distortion / Overdrive | 增益类音色效果 |
| 混响/延迟 | Reverb / Delay | 空间类效果 |
| 声卡 | Audio interface | 录音的输入设备 |
| 直录 | DI | 乐器直接录入 |
| 调弦 | Tuning | 各弦的音高设置 |
| 异弦调弦 | Altered tuning | 非标准调弦(如 DADGAD) |
