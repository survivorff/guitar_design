## 关于"找资源"的心法

- **资源不是越多越好**:贪多反而焦虑、分散。选 1–2 个适合你的主力资源,深入用透。
- **聆听是最好的老师**:多听好音乐,胜过看一百个教程。耳朵养好了,手自然跟上。
- **找社区/同伴**:有人交流、被人反馈,进步更快也更有乐趣。
- **老师的价值**:如果条件允许,哪怕几节课的专业老师,也能帮你纠正姿势、指明方向,少走很多弯路。
