# 🎼 乐谱与练习软件

光看文字和静态图不够,真正"专业的练习"需要能**看谱、听声、变速、循环**的工具。
这一篇介绍如何用软件把本知识库的内容变成可交互的练习,以及主流乐谱/练习软件。

---

## 一、本仓库自带的交互练习台 ⭐

仓库里有一个**开箱即用的网页练习台**:[`interactive/练习台.html`](../interactive/练习台.html)

**功能**:
- 看五线谱 + 六线谱(TAB)
- 点击播放,**听到**每首练习曲的声音
- **变速**(25%–150%):慢速跟练,逐步提速
- **节拍器**开关、**循环**开关(磨难点)
- 内置:小星星、欢乐颂、A 小调五声、12 小节布鲁斯伴奏

**怎么打开**:
- 直接用浏览器打开 `interactive/练习台.html` 文件即可(双击,或拖进浏览器)。
- 首次需要联网(从 CDN 加载 alphaTab 引擎和音色库),之后谱子本身是本地的。

**怎么加自己的曲子**:
- 用文本编辑器打开 `练习台.html`,找到 `SONGS` 部分,按里面的 alphaTex 语法添加。
- alphaTex 语法极简:`3.1` = 1弦3品,`:4` = 四分音符,`|` = 小节线。详见下方。

## 二、alphaTex 记谱速查(写自己的谱子)

alphaTab 用的 alphaTex 是一种纯文本记谱,易学易改、可版本管理。

### 基本语法
```
\title "曲名"        ← 标题
\tempo 100           ← 速度 BPM
.                    ← 元数据结束符(别漏)

音符写法:品.弦
  3.1   → 第1弦第3品
  0.6   → 第6弦空弦
  r     → 休止符

时值(写在音符前,持续生效到下次改变):
  :1 全音符  :2 二分  :4 四分  :8 八分  :16 十六分

和弦/同时发声:用括号
  (0.5 2.4)  → 同时弹 5弦空弦 和 4弦2品

小节线:|
```

### 一个完整例子
```
\title "C 和弦分解" \tempo 80 .
:8 3.5 2.4 0.3 1.2 0.1 1.2 0.3 2.4 |
```

### 技巧记号(进阶)
```
3.3{h}   击弦 hammer-on
5.3{b}   推弦 bend
7.3{sl}  滑音 slide
3.3{v}   揉弦 vibrato
```

> 更多语法见 alphaTab 官方文档(搜索 "alphaTab alphaTex")。

## 三、主流乐谱 / 练习软件对比

| 软件/平台 | 类型 | 特点 | 适合 |
|-----------|------|------|------|
| **alphaTab** | 开源库/网页 | 免费、可嵌网页、本仓库在用 | 自建练习页、开发者 |
| **Guitar Pro** | 桌面软件(付费) | 行业标准,编辑/播放/变速/音色丰富 | 认真扒谱、写谱、练习 |
| **TuxGuitar** | 桌面软件(免费开源) | 类似 Guitar Pro,能开 .gp 文件 | 预算有限的替代品 |
| **Songsterr** | 网站/App | 海量带播放的 TAB,可变速、循环、独奏轨 | 在线跟练曲子 |
| **MuseScore** | 桌面+网站(免费) | 五线谱为主,排版精美,社区谱多 | 古典、读五线谱、打谱 |
| **Ultimate Guitar** | 网站/App | 最大 TAB/和弦库,Pro 版带播放 | 找谱、和弦弹唱 |
| **Moises / Spotify 等变速** | App | 把任意音频变速不变调、扒带分轨 | 扒谱、跟原曲练 |

### 文件格式小知识
- `.gp` / `.gp5` / `.gpx`:Guitar Pro 格式,最通用的 TAB 谱文件(TuxGuitar 也能开)。
- `.mscz`:MuseScore 格式。
- `.xml` / `.musicxml`:通用乐谱交换格式,多数软件互通。
- `.alphatab` / alphaTex:本仓库用的文本格式。

## 四、必备的"练习类"工具(再强调)

无论用哪个谱子软件,这几类练习工具都该常备(详见 [必备配件.md](../03-装备与配置/必备配件.md)):

- **节拍器**:练节奏的命根子(很多谱子软件内置)。
- **变速播放器**:把原曲放慢不变调,扒谱/跟练神器(Songsterr、Moises、各类播放器)。
- **循环(A-B repeat)**:反复磨某一小段。
- **录音**:手机就行,回听是最诚实的反馈。

---

## 五、推荐的"专业练习"工作流

```
1. 找谱/扒谱:Songsterr / Ultimate Guitar / Guitar Pro 文件,或自己扒(最推荐)
2. 慢速看谱跟练:用软件把速度降到 50–60%,开节拍器,跟着光标弹
3. 分段循环:把难点小节设为 A-B 循环,反复练到顺
4. 逐步提速:每次 +5~10%,只在能弹对的速度提
5. 脱谱演奏:能不看谱弹下来
6. 录音自检:录一遍回听,找问题,回到第 3 步
```

> 本仓库的 `interactive/练习台.html` 已经把"看谱+播放+变速+循环+节拍器"打包好了,
> 入门练习曲可以直接用它开始。更复杂的曲子用 Guitar Pro / Songsterr。
