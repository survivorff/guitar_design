# 🧰 学习资源与工具

这里汇总常见的学习资源**类型和方向**(具体平台/产品会随时间变化,请结合搜索使用最新的)。

---

## 一、练习类 App / 工具

| 类型 | 用途 | 说明 |
|------|------|------|
| **调音器 App** | 调音 | GuitarTuna 等,免费够用 |
| **节拍器 App** | 练节奏 | 很多调音器自带;也有专门的节拍器 App |
| **变速播放器** | 扒谱、慢练 | 能变速不变调,循环 A-B 段(扒谱神器) |
| **TAB 软件/App** | 看谱、写谱 | Guitar Pro、Songsterr 等,可看带节奏的 TAB 并慢放 |
| **和弦查询** | 查指型 | 各类和弦字典 App/网站 |
| **Backing track** | 即兴练习 | 视频平台搜"调性 + 风格 + backing track" |
| **录音/DAW** | 录音、制作 | GarageBand、各类 DAW |
| **amp sim** | 电吉他在家出音色 | 各种音箱模拟软件/综合效果器 |

## 二、TAB / 曲谱来源

- **综合 TAB 网站**:海量用户上传的 TAB(质量参差,多对比几个版本)。
- **带播放的 TAB 平台**:能边听边看谱、可慢放,适合学曲子。
- **官方/正版谱**:质量高、准确,部分付费。
- **自己扒谱**:最推荐,见 `08/扒谱与听力.md`——扒一遍胜过看十遍谱。

## 三、视频教程方向

视频是当代学吉他最丰富的资源。建议:
- **找系统的入门系列**(成体系的课程比零散视频更适合打基础)。
- **找专项教学**(针对某个技巧:大横按、推弦、扫弦等)。
- **找"慢放+多角度"的演奏视频**(扒谱、模仿手型)。
- **找演奏视频**(看大师怎么处理,光听学不到的视觉信息)。

> 提示:跟视频学要**动手练**,别变成"看教程上瘾但不练"。看 20 分钟不如练 20 分钟。

## 四、书籍方向(经典类型)

- **乐理入门书**:系统讲音名、音阶、和弦、和声(选适合吉他手的)。
- **技巧/练习册**:音阶琶音、爬格子、专项技巧的系统练习。
- **古典吉他教材**:成体系的古典教程(含五线谱、练习曲)。
- **风格专项**:布鲁斯/爵士/指弹等的专门教材。
- **经典练习曲集**:如古典的 Sor/Carcassi、各风格的标准练习。

## 五、线上课程平台

- 有结构化的吉他课程平台(分级、有计划、有反馈),适合想系统学又自律不足的人。
- 优点:成体系、循序渐进;缺点:需要付费、需要自律跟完。

## 六、找一位老师(强烈建议,如果条件允许)

- **真人老师的不可替代价值**:
  - 当面纠正姿势(姿势错误自己很难发现)。
  - 针对你的问题即时反馈、对症下药。
  - 帮你规划路径,少走弯路。
- 形式:线下一对一、线上视频课均可。
- 哪怕只上几节课打基础、定期"复诊",也很值得。

## 七、社区与同伴

- **线上社区/论坛**:提问、分享、找谱、看别人的进步。
- **本地琴友/乐队**:一起玩、合奏、互相激励——音乐本质是社交的。
- **开放麦/演出**:实战机会,逼自己进步(见 `10/舞台表演.md`)。
