# 🎬 媒体资源中心(示范 · 音频 · 视频 · 演出)

文字和图示能讲清"是什么、怎么做",但**示范视频、音频、演出录像**才能让你真正"看到、听到"。
这一篇汇总了大量可直接点击访问的资源,分为四类:

1. **教学示范频道**(系统学 + 技巧示范)
2. **聆听 / 音频**(必听演奏、专辑)
3. **演出 / 现场视频**(Live、音乐节、大师现场)
4. **跟练资源**(伴奏、慢放、扒谱)

> ⚠️ 关于链接:外部内容由第三方托管,链接可能随时间失效或变更。本文档同时提供
> **"智能搜索链接"**(点击即在平台搜索关键词),即使某个具体视频失效,搜索链接也始终有效。
> 所有链接都指向公开、合法的平台,请尊重创作者版权。

## 🧭 怎么用这个中心

- **想系统学** → 看第一节"教学频道",选 1–2 个主力跟到底。
- **想找某技巧/某首歌的示范** → 用第四节的"智能搜索链接",填入关键词秒搜。

## 三、🎤 演出 / 现场视频(感受音乐的能量与现场艺术)

看现场不只是娱乐,更能学到:**舞台表现、乐队配合、即兴互动、音色处理、肢体语言**。

### 经典现场 / 纪录片方向(YouTube 搜索直达)
- [Woodstock 经典吉他演出](https://www.youtube.com/results?search_query=Woodstock+guitar+performance)
- [Crossroads Guitar Festival](https://www.youtube.com/results?search_query=Crossroads+Guitar+Festival)(Clapton 发起,布鲁斯/摇滚名家云集)
- [Montreux Jazz Festival guitar](https://www.youtube.com/results?search_query=Montreux+Jazz+Festival+guitar)
- [NPR Tiny Desk Concert](https://www.youtube.com/results?search_query=Tiny+Desk+Concert+guitar)(小型原声现场,音色和细节清晰)
- [Mahogany Sessions](https://www.youtube.com/results?search_query=Mahogany+Session+acoustic)(高质量原声/民谣现场)

### 官方现场频道 / 平台
- **Tiny Desk(NPR Music)**:[@nprmusic](https://www.youtube.com/@nprmusic)
- **Montreux Jazz Festival**:[官网](https://www.montreuxjazzfestival.com/)
- 大量乐队有**官方 YouTube 频道**,搜"乐队名 + official"找到后看其 Live 播放列表。

### 怎么"主动看"演出(而不只是被动听)
1. 第一遍:整体感受情绪和能量。
2. 第二遍:盯着吉他手——右手怎么扫/拨、左手在哪个把位、什么时候推弦揉弦。
3. 第三遍:看乐队互动——和鼓手/贝斯怎么对眼神、怎么切段落。
4. 挑一个打动你的瞬间,去扒它(见第四节)。

> 详细的"如何从演出中学习"见 [10-艺术与表达/舞台表演.md](../10-艺术与表达/舞台表演.md)。

## 四、🎸 跟练资源(伴奏 · 慢放 · 扒谱)

### 伴奏音轨(Backing Tracks,即兴必备)
- **Quist**:[quistorama.com/jamtracks](https://quistorama.com/jamtracks) · [YouTube @Quist](https://www.youtube.com/@Quist) —— 各调各风格海量免费伴奏
- **Elevated Jam Tracks**:[elevatedjamtracks.com](https://elevatedjamtracks.com/) —— 含免费 TAB + 伴奏
- 通用搜索:[YouTube 搜 "A minor blues backing track"](https://www.youtube.com/results?search_query=A+minor+blues+backing+track)
  —— 把 "A minor blues" 换成你要的"调+风格"即可。

### 变速 / 慢放工具(扒谱、跟难句)
- **YouTube 自带**:播放时点 ⚙️设置 → 播放速度(0.25x–2x),扒谱神器,免费。
- **Moises**:[moises.ai](https://moises.ai/) —— 变速不变调 + 分离人声/乐器轨(扒带利器)
- **Songsterr**:[songsterr.com](https://www.songsterr.com/) —— 带播放的 TAB,可变速、循环、单独听某轨

### 找谱
- **Ultimate Guitar**:[ultimate-guitar.com](https://www.ultimate-guitar.com/) —— 最大和弦/TAB 库
- **Songsterr**:[songsterr.com](https://www.songsterr.com/) —— 带播放的交互 TAB
- 详见 [乐谱与练习软件.md](./乐谱与练习软件.md)

## 五、🔎 智能搜索链接(填关键词秒搜,永不失效)

具体视频可能下架,但搜索链接永远有效。**把下面 URL 里的关键词换成你想找的内容**即可。

### 找"某技巧"的示范
- YouTube:`https://www.youtube.com/results?search_query=` + 关键词
  - 例:[guitar bending technique lesson](https://www.youtube.com/results?search_query=guitar+bending+technique+lesson)
  - 例:[barre chord F how to](https://www.youtube.com/results?search_query=barre+chord+F+how+to)
- B 站(中文):`https://search.bilibili.com/all?keyword=` + 关键词
  - 例:[大横按 技巧](https://search.bilibili.com/all?keyword=大横按%20技巧)
  - 例:[吉他 推弦 教学](https://search.bilibili.com/all?keyword=吉他%20推弦%20教学)

### 找"某首歌"的教学/演奏
- YouTube:[歌名 + guitar tutorial](https://www.youtube.com/results?search_query=song+name+guitar+tutorial)
- B 站:[歌名 + 吉他教学](https://search.bilibili.com/all?keyword=歌名%20吉他教学)

### 找"某位演奏者"
- YouTube:[演奏者名 + live / lesson / interview](https://www.youtube.com/results?search_query=guitarist+name+live)

## 六、📌 给学习者的提醒

- **别变成"看视频上瘾但不练"**:看 20 分钟不如练 20 分钟。看完一定要拿起琴动手。
- **挑 1–2 个主力频道跟到底**,别每个都浅尝。
- **看演出要"主动看"**(见第三节方法),把灵感转化为练习目标。
- **尊重版权**:这些链接指向创作者公开发布的内容,支持你喜欢的创作者(订阅、正版、周边)。
