# 11 · 练习计划与方法

知道"练什么"之后,还要知道"怎么安排练"。这个模块提供可直接使用的练习模板、
进度追踪工具,帮你把零散的学习变成有效的、可持续的成长。

## 本模块内容

- [每日练习模板.md](./每日练习模板.md) —— 不同时长、不同阶段的练习安排
- [周计划与月目标.md](./周计划与月目标.md) —— 如何设定和拆解目标
- [进度追踪.md](./进度追踪.md) —— 记录数据、自测、见证进步

## 高效练习的核心(回顾)

来自 `00/练习心法.md` 的几条铁律:
1. **慢、准、稳,然后才快。**
2. **少量多次** > 长时间突击。
3. **练你不会的**,而非反复弹你已经会的。
4. **用节拍器、录音**做即时反馈。
5. **每次留时间纯粹享受**地弹。

## 怎么用这个模块

- 新手:直接套用 `每日练习模板` 里的入门版。
- 想系统进步:用 `周计划与月目标` 设定方向,用 `进度追踪` 监测。
- 没时间:哪怕只有 10 分钟,也按"迷你模板"练,保持连续性最重要。
