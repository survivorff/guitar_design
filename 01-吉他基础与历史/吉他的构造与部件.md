# 🪕 吉他的构造与部件

认识吉他的每个部件,你才能看懂教程术语、选琴、调试、保养。
下面按"琴头 → 琴颈 → 琴身"的顺序讲解,并标注原声吉他与电吉他的差异。

---

## 整体三大部分

```
   琴头(Headstock)
      │
   琴颈(Neck)
      │
   琴身(Body)
```

---

## 一、琴头(Headstock)

| 部件 | 英文 | 作用 |
|------|------|------|
| 弦钮 / 调音旋钮 | Tuning pegs / Machine heads | 旋转改变弦的张力,从而调音 |
| 弦枕(上枕) | Nut | 琴头与琴颈交界的卡槽,决定开放弦的弦高与间距 |
| 品牌标志 | Logo | 制造商标识 |

> 弦从琴桥拉到弦钮,缠绕在弦钮的弦轴上,旋转弦钮即调节音高。

## 二、琴颈(Neck)与指板(Fretboard)

| 部件 | 英文 | 作用 |
|------|------|------|
| 指板 | Fretboard / Fingerboard | 按弦的表面,通常黑檀、玫瑰木或枫木 |
| 品丝 | Frets | 嵌在指板上的金属条,把弦分成半音 |
| 品格 | Fret (position) | 两根品丝之间的区域,从琴头数第 1 品、第 2 品…… |
| 品位记号 | Inlays / Position markers | 常在 3/5/7/9/12 品,帮助定位 |
| 钢筋 / 调节杆 | Truss rod | 琴颈内部钢杆,调节琴颈弯曲度 |

**关于品(fret)**:每过一品 = 升高一个半音。第 12 品是开放弦音高的高八度(弦长一半)。

## 三、琴身(Body)

### 原声吉他(Acoustic)

| 部件 | 英文 | 作用 |
|------|------|------|
| 共鸣箱(面板/侧板/背板) | Soundboard / Sides / Back | 放大并塑造弦的振动,面板材质对音色影响最大 |
| 音孔 | Soundhole | 让箱体内空气共振、声音传出 |
| 音梁 | Bracing | 面板内部的木条结构,影响强度与音色(X-bracing 等) |
| 琴桥 | Bridge | 固定弦的下端,把振动传到面板 |
| 下枕 | Saddle | 琴桥上的条,决定弦的振动起点与弦高 |
| 弦钉 | Bridge pins | 固定钢弦球头(古典吉他用打结固定,无弦钉) |
| 护板 | Pickguard | 保护面板不被拨片刮伤 |

**常见面板木材**:云杉(spruce,明亮通透)、雪松(cedar,温暖)、红木/桃花心木等。

### 电吉他(Electric)

| 部件 | 英文 | 作用 |
|------|------|------|
| 实心/半空心琴体 | Solid / Semi-hollow body | 减少反馈,塑造基础音色 |
| 拾音器 | Pickups | 把弦的振动转成电信号(单线圈 single-coil / 双线圈 humbucker) |
| 拾音器切换开关 | Pickup selector | 选择使用哪个拾音器或组合 |
| 音量/音色旋钮 | Volume / Tone knobs | 调节输出音量与高频量 |
| 琴桥 / 拉弦系统 | Bridge / Tremolo (whammy) | 固定弦,部分带摇把可改变音高 |
| 输出插孔 | Output jack | 连接吉他线到音箱/效果器 |

---

## 四、弦(Strings)

- 标准 6 弦从**最粗到最细**编号为 **6 → 1**。
- 标准调弦音名:**6=E, 5=A, 4=D, 3=G, 2=B, 1=E**(低音 E 到高音 E)。
- 记忆口诀(从粗到细):**E**very **A**dult **D**og **G**rowls **B**arks **E**ats。
- 材质:
  - **尼龙弦**:古典吉他用,音色柔和,张力小,对指尖友好。
  - **钢弦**:民谣/电吉他用,音色明亮,张力大,初期更"咬手"。

---

## 五、部件如何影响音色(速查)

| 想要的改变 | 可调部件 |
|------------|----------|
| 音高(调音) | 弦钮 |
| 弦高 / 手感 | 下枕(saddle)、琴颈钢筋 |
| 整体音色明暗 | 面板木材、弦的材质与新旧 |
| 电吉他音色 | 拾音器类型、切换开关、音色旋钮、效果器 |
| 演奏舒适度 | 琴颈宽度/弧度、琴体大小 |

---

## 📐 弦与品的坐标系统

教程里描述位置常用"X 弦 Y 品":
- "5 弦 3 品" = 第 5 弦(A 弦)上第 3 个品格按下,得到 C 音。
- "0" 或 "空弦" = 不按任何品,直接弹该弦。

这个坐标系统是看懂 TAB 谱和和弦图的基础,务必熟记。
