# 🔊 声音是怎么产生的

理解吉他发声的物理原理,你就会明白:为什么换弦后音色更好、为什么这样拨弦更亮、
为什么琴体大小影响音量。这一篇用直觉化的方式讲清楚原理。

---

## 一、声音的本质:振动

- 声音是**空气的振动(声波)**传到你的耳朵。
- 吉他的声音始于**琴弦的振动**。拨动一根弦,它来回摆动,推动周围空气形成声波。

## 二、音高由什么决定

一根弦振动的频率(每秒振动次数,单位 Hz)决定音高。频率越高,音越高。三个因素决定频率:

1. **弦的长度**:越短音越高。按品=缩短振动弦长=升高音高。
2. **弦的张力**:越紧音越高。拧紧弦钮=增大张力=升高音高(这就是调音)。
3. **弦的质量/粗细**:越粗越重音越低。所以低音弦比高音弦粗。

> 这三点解释了吉他的一切音高变化:换弦(粗细)、调音(张力)、按品(长度)。

## 三、原声吉他:共鸣箱的放大

- 单靠一根弦振动,声音非常小。
- 弦的振动通过**琴桥**传给**面板(soundboard)**。
- 面板面积大,带动大量空气振动,音量被放大;箱体内空气共振进一步增强、塑造音色。
- 所以:
  - **面板材质和厚度**对音色影响最大(它是真正的"发声体")。
  - **箱体越大**通常低频越饱满、音量越大。
  - 音孔让箱内外空气交换,参与共振(亥姆霍兹共鸣)。

## 四、电吉他:电磁拾音

- 实心电吉他几乎没有共鸣箱,直接靠弦振动很轻。
- **拾音器(pickup)** 是缠了上千圈铜线的磁铁。钢弦在磁场中振动,会在线圈里**感应出微弱电流**(电磁感应)。
- 这个电信号经吉他线送到**音箱**,被放大成声音。
- 因此电吉他的音色取决于:**拾音器类型 + 电路 + 音箱 + 效果器**,而非箱体共鸣。
  - **单线圈(single-coil)**:清亮、通透,但易拾取交流杂讯。
  - **双线圈(humbucker)**:厚实、输出大、抗杂讯,适合摇滚金属。

## 五、泛音(Harmonics)与音色

- 弦振动时不只产生一个频率,还同时产生一系列**泛音(整数倍频率)**。
- 泛音的比例和强弱构成了"音色(timbre)"——同一个音,吉他和钢琴听起来不同,就是泛音结构不同。
- 拨弦的**位置**会改变泛音:
  - 靠近琴桥拨 → 高频泛音多 → 音色明亮、尖锐(古典里叫 *sul ponticello*)。
  - 靠近音孔/指板拨 → 基频强 → 音色圆润、温暖(*sul tasto*)。
- 轻触弦的 1/2、1/3 等节点可奏出**自然泛音(natural harmonics)**,发出清亮的钟声般音色。

## 六、延音(Sustain)与衰减

- 拨弦后声音会逐渐变弱(衰减),持续时间叫**延音**。
- 影响延音的因素:弦的质量、琴体材质与结构、弦与琴的能量耦合。
- 电吉他可借助失真/压缩/音箱增益获得很长的延音,这也是电吉他歌唱性 solo 的基础。

---

## 🎯 这些原理的实用价值

| 你观察到的现象 | 背后的原理 |
|----------------|------------|
| 调音就是拧弦钮 | 改变张力→改变频率 |
| 按品音变高 | 缩短振动弦长 |
| 旧弦音色发闷 | 弦上积污、失去弹性,泛音减少 |
| 靠桥拨弦更"刺" | 激发更多高频泛音 |
| 大琴箱低音足 | 更大面板/箱体带动更多空气 |
| 电吉他换拾音器音色变 | 改变了信号的频率响应 |
