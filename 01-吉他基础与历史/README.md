# 01 · 吉他基础与历史

了解你手中的乐器:它从哪来,由什么组成,经历了怎样的演变。
建立对乐器本身的认识,会让你的学习更有根、更有温度。

## 本模块内容

- [吉他的历史与演变.md](./吉他的历史与演变.md) —— 从古代弦乐器到现代吉他的千年旅程
- [吉他的构造与部件.md](./吉他的构造与部件.md) —— 每个部件的名称、作用与对音色的影响
- [声音是怎么产生的.md](./声音是怎么产生的.md) —— 振动、共鸣、拾音的物理原理

## 为什么要学这些

- 懂构造,你才知道怎么选琴、调琴、保养琴、判断琴的好坏。
- 懂历史,你才能理解不同风格为什么是现在这个样子。
- 懂原理,你才明白为什么这样拨弦音色更好。
