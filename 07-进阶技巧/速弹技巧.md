# ⚡ 速弹技巧(Speed Techniques)

速弹是技术的"极限运动"。它本身不是音乐的目的,但掌握它能极大拓展你的表达边界。
**铁律:速度是干净的副产品。慢练对了,快自然来。**

---

## 一、经济拨弦(Economy Picking)

在交替拨弦基础上的优化:**换弦时朝同一方向"顺势扫过"**,减少多余动作。
- 例:从一根弦下拨到下一根弦时,也用下拨(顺势),而非强行上拨。
- 比纯交替拨弦在某些乐句上更省力、更快。
- 难点:保持音色均匀,不因"顺势"而漏拍。

## 二、扫拨 / 扫弦点弦(Sweep Picking)

弹琶音时,拨片像"扫"一样**一个方向连续划过多根弦**,每根弦只发一个音,左手配合精准地逐个按下/抬起。

```
Am 琶音扫拨示例:
e|----------12----------|
B|-------13-------13-----|
G|----12-------------12--|
D|-14----------------14--|   (一个下扫连续扫过, 上行)
A|----------------------|
E|----------------------|
```
- **关键**:左手手指要**逐个"滚动"按下并立刻抬起**,保证每个音清晰、不连成一片("打架"是最大难题)。
- 右手扫弦要匀速、放松,像刷漆。
- 新古典金属(Yngwie Malmsteen)的标志技巧。
- **极慢练**:这是最需要慢练的技巧之一,快了就糊。

## 三、点弦(Tapping,记号 t)

用**右手手指**直接"点击"品格发声,与左手击勾弦结合,实现超大跨度和快速音群。

### 基础双手点弦
```
e|--12t--8p5--5h8--12t--8p5--... (t=右手点弦, h/p=左手击勾)
```
- 右手食指或中指像击弦一样**砸**向品格,再**勾**着离弦带出左手按好的音。
- Eddie Van Halen 的《Eruption》让它名声大噪。
- 可做出大跨度琶音、快速音阶跑动。

### 要点
- 右手点弦也要**勾着离弦**(像 pull-off),否则后面的音不响。
- 不点弦时,右手要**闷住**其他弦防杂音(电吉他高增益下尤其重要)。

## 四、轮指 / 颤音(Tremolo / Trills)

- **右手快速 tremolo picking**:在一个音上极快地交替拨弦(如金属、古典轮指效果)。
- **左手 trill**:`h/p` 快速来回(见连奏篇)。
- 古典吉他的**轮指(tremolo)**:p-a-m-i 快速循环,营造"持续音"的错觉(《阿尔罕布拉宫的回忆》)。

## 五、怎么科学地练速度

1. **节拍器渐进法**(核心):
   ```
   找到你能 100% 弹干净的速度 → 弹对 3-5 遍 → +4~5 BPM → 重复
   出错就退回,绝不在出错的速度硬练
   ```
2. **分块**:把快速乐句拆成 2-4 音的小块,各个击破再连接。
3. **节奏变化练习**:把均匀的音符改成附点节奏(长短长短)来练,能突破瓶颈。
4. **放松至上**:速度的最大敌人是紧张。任何时候发现手臂/肩膀僵硬,立刻放松降速。
5. **左右手同步**:速弹瓶颈常在左右手不同步,慢练时刻意对齐每个拨弦与按弦。

## 六、心态提醒

- 速弹很酷,但**音乐性 > 速度**。能弹很快却没乐感,听众不会感动。
- 把速弹当成"工具箱里的一件工具",而不是终极目标。
- 很多伟大的演奏者并不以速度见长,却极其动人。
