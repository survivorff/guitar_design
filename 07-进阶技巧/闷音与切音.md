# 🤫 闷音与切音(Muting & Palm Mute)

控制"不响"和控制"响"同样重要。闷音让演奏干净、有节奏质感,是摇滚、放克、金属的核心音色之一。

---

## 一、右手手掌闷音(Palm Mute,记号 P.M.)

用右手手掌**外侧边缘**轻轻靠在**靠近琴桥**的弦上,同时拨弦,得到"闷、紧、闷哼哼"的音色。

### 要点
- 手掌靠的位置在**琴桥附近**:越靠桥越闷越短;往指板方向移会逐渐恢复正常音色。
- 力度决定闷的程度:轻搭=半闷有音高,重压=几乎只剩"噗"。
- 主要用在低音弦(强力和弦),配合下拨。

### 应用
- **摇滚/金属节奏吉他**:`P.M.` 的强力和弦"咚咚咚"扫击是金属律动的标志。
- **冲浪摇滚、放克**:制造紧凑有弹性的节奏。

```
e|--------------------|
B|--------------------|
G|--------------------|
D|--5--5--5--5--------|
A|--5--5--5--5--------|
E|--3--3--3--3--------|
   P.M.------------- (手掌闷音 + 下拨)
```

## 二、左手闷音(Fretting-hand muting)

用左手指**轻搭**在弦上(不按实),拨弦只发出"嚓/哑"的无音高打击声(记号常为 `x`)。

### 应用
- **放克节奏**:`x` 的"嚓嚓"声 + 偶尔的和弦,制造律动(funk scratch)。
- **消除杂音**:弹单音/solo 时,左手余指轻搭不弹的弦,防止它们共振出杂音。
- **切音(staccato)**:和弦扫响后,左手立刻松力(不离弦)把声音"掐断",得到短促有力的效果。

## 三、切音(Staccato / Choking)

让音符**短促、干脆地停止**,与连音(legato)相对。

- **左手切音**:扫/拨响后,按弦手指松开力度(保持触弦)止音。
- **右手切音**:用手掌或重新搭弦止音。
- 放克、雷鬼、流行节奏吉他大量用切音制造"弹性"和呼吸感。

## 四、综合应用:让节奏"会呼吸"

- 闷音/切音 + 正常发声交替,是节奏吉他"律动感"的核心。
- 例:放克里大量"嚓嚓嚓"(闷)中间点缀清晰和弦(响),配合十六分音符律动。
- 金属里全程 palm mute 的低音 riff + 偶尔放开的和弦,制造张力对比。

## 五、练习方法

1. **palm mute 单练**:在低音弦上,找手掌位置,练到能稳定输出闷音色,跟节拍器弹八分音符。
2. **闷/放交替**:`P.M.闷音 → 放开和弦 → 再闷`,练控制。
3. **放克 scratch**:左手全程轻搭做 `x x x x` 律动,偶尔按下和弦,练右手十六分音符律动。
4. **切音练习**:扫一个和弦,立刻切断,追求干净利落的"哒!"。
