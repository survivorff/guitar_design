# 07 · 进阶技巧

当基础扎实后,这些技巧会让你的演奏更有表现力、更"专业"。它们是旋律歌唱性、
solo 表达和炫技的工具。重点:**每个技巧都要慢练、求音色干净,再求速度。**

## 本模块内容

- [连奏技巧:击弦勾弦与滑音.md](./连奏技巧-击弦勾弦与滑音.md) —— 让音符连贯流动
- [推弦与揉弦.md](./推弦与揉弦.md) —— 电吉他/布鲁斯的"歌唱"灵魂
- [闷音与切音.md](./闷音与切音.md) —— palm mute 与控制
- [泛音.md](./泛音.md) —— 自然泛音、人工泛音
- [速弹技巧.md](./速弹技巧.md) —— 经济拨弦、扫拨、点弦
- [现代指弹技巧.md](./现代指弹技巧.md) —— 打板、敲击、异弦调音

## 学习态度

- 这些技巧不是"学会就行",而是要练到能**在音乐中自然运用**且**音色优美**。
- 一个揉弦的好坏,往往比能弹多快更能体现演奏者的水平。
- 不要为炫技而炫技——技巧服务于音乐表达。

## 与阶段的关系

进阶技巧对应学习路线的"进阶→精通"阶段。掌握它们后,
你就具备了演奏大多数风格代表曲目的技术工具。
