# 12 · 曲目库

曲目是把所有知识技巧"落地"的地方。这个模块按**难度**和**风格/类型**整理练习曲方向,
帮你在每个阶段找到合适的目标曲,循序渐进。

## 本模块内容

- [按难度分级.md](./按难度分级.md) —— 从第一首到挑战级,逐级推进
- [按风格分类.md](./按风格分类.md) —— 各风格代表曲目方向
- [手把手练习曲.md](./手把手练习曲.md) —— 带完整 TAB、可直接上手的练习曲
- [我的曲目清单.md](./我的曲目清单.md) —— 记录你想学、在学、已会的曲子

## 怎么用曲目库

1. **选适合当前水平的**:太难会挫败,太易没成长。选"跳一跳够得着"的。
2. **选你真心喜欢的**:动力第一。喜欢的歌你会愿意反复练。
3. **一次专注 1–2 首**:弹到能完整演奏,再开新的,别贪多。
4. **难点单独抠**:把曲子里最难的小节拆出来重点练。

## 关于具体曲谱

这个库提供的是**曲目方向和清单**,具体的 TAB/谱子可以:
- 在网上搜索(很多免费 TAB 网站和视频教程)。
- 用 `08/扒谱与听力.md` 的方法自己扒(强烈推荐,进步最快)。
- 把找到的好谱/链接记到 `我的曲目清单.md`。

> 提示:挑曲子时,同一首歌常有"简化版"和"原版",新手先弹简化版,有成就感再进阶。
