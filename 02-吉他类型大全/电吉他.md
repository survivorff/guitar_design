# ⚡ 电吉他(Electric Guitar)

靠拾音器发声,音色极其多变。它是摇滚、布鲁斯、金属、放克、爵士和现代流行的核心乐器。

---

## 特征

- **细钢弦 + 薄而窄的琴颈**:手感轻快,适合快速演奏、推弦、技巧型乐句。
- **拾音器决定音色**:不靠箱体共鸣。
- **必须配音箱/效果器**才能完整发挥(也可插耳机静音练习,适合公寓)。
- **弦距通常很低**:好按、好推弦。

## 主要类型与经典型号

| 类型 | 经典型号 | 音色特点 | 常见风格 |
|------|----------|----------|----------|
| 实心-单线圈 | Fender Stratocaster | 清亮、通透、有"玻璃感" | 布鲁斯、放克、流行、摇滚 |
| 实心-单线圈 | Fender Telecaster | 明亮、咬人、清脆 | 乡村、摇滚、流行 |
| 实心-双线圈 | Gibson Les Paul | 厚实、温暖、延音长 | 摇滚、硬摇滚、金属 |
| 实心-双线圈 | Gibson SG | 轻、凶、中频突出 | 硬摇滚、重金属 |
| 超级琴(Superstrat) | Ibanez RG、Jackson 等 | 输出大、利于速弹、带摇把 | 金属、速弹 |
| 半空心 | Gibson ES-335 | 温暖带共鸣、半原声感 | 爵士、布鲁斯、复古摇滚 |
| 空心(Archtop) | Gibson L-5 等 | 圆润、温暖 | 传统爵士 |

## 拾音器:音色的核心

- **单线圈(Single-coil)**:清亮、细节多,但易拾交流杂讯(60Hz hum)。代表:Strat、Tele。
- **双线圈(Humbucker)**:两个线圈反向消噪,音色厚、输出大、抗噪。代表:Les Paul。
- **切换开关**:可选不同拾音器或组合,瞬间改变音色(琴桥拾音器亮、琴颈拾音器暖)。

## 信号链(Signal Chain)

```
吉他 → (效果器们) → 音箱 → 喇叭 → 你的耳朵
```

常见效果器(详见 `03-装备与配置`):
- **失真/过载(Distortion / Overdrive)**:摇滚金属的标志音色。
- **混响(Reverb)/ 延迟(Delay)**:空间感。
- **哇音(Wah)**:扫频,Hendrix、放克常用。
- **压缩、合唱、镶边、相位**等等。

> 现代可用**数字建模(amp sim / 综合效果器)**在耳机里获得各种专业音色,极适合在家练。

## 适合的风格

几乎所有现代流行音乐:摇滚、布鲁斯、金属、放克、爵士、流行、R&B、朋克……

## 代表人物与必听

- **Jimi Hendrix**:重新定义了电吉他的表现力与音色,绕不开的神。
- **Eric Clapton、B.B. King、Stevie Ray Vaughan**:布鲁斯方向。
- **Jimmy Page、David Gilmour、Slash**:经典/前卫摇滚。
- **Eddie Van Halen**:点弦革命("Eruption")。
- **Yngwie Malmsteen、Steve Vai、Joe Satriani**:新古典/技巧型速弹。
- **John Scofield、Pat Metheny、Wes Montgomery**:爵士吉他。

## 入门要点

- 电吉他**单独干弹声音很小很干**,需要音箱/耳机声卡才有"那个味儿"。
- 初期重点同样是和弦、节奏、五声音阶,不要一上来只追求速弹。
- **推弦(bending)、击勾弦、闷音(palm mute)**是电吉他的灵魂技巧,见 `07-进阶技巧`。
- 配置一套耳机练习方案(综合效果器/声卡 + 耳机)能让你随时安静地练。
