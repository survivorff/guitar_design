# 02 · 吉他类型大全

"吉他"是一个大家族。不同类型在构造、音色、演奏方式、适用风格上差异巨大。
了解它们,能帮你选对入门琴,也能理解不同音乐为什么用不同的吉他。

- [古典吉他.md](./古典吉他.md) —— 尼龙弦,古典与弗拉门戈
- [原声民谣吉他.md](./原声民谣吉他.md) —— 钢弦,弹唱与指弹主力

## 快速选琴建议

| 你的目标 | 推荐入门类型 |
|----------|--------------|
| 弹唱流行/民谣 | 原声民谣吉他(钢弦) |
| 古典/指弹艺术 | 古典吉他(尼龙弦)或指弹钢弦琴 |
| 摇滚/金属/布鲁斯 | 电吉他 |
| 手指怕疼、想轻松起步 | 古典吉他(尼龙弦更软)或尤克里里 |
| 乐队低音声部 | 贝斯 |
