# 🎸 吉他类型总览

下面是吉他大家族的全景对比,帮你快速建立认识。后面每个类型都有单独的详解文件。

---

## 一、三大主流类型对比

| 维度 | 古典吉他 | 原声民谣吉他 | 电吉他 |
|------|----------|--------------|--------|
| 弦 | 尼龙弦 | 钢弦 | 钢弦(较细) |
| 音色 | 柔和、温暖、圆润 | 明亮、清脆、洪亮 | 取决于设备,极其多变 |
| 琴颈 | 宽、平 | 较窄 | 窄、薄,易快速演奏 |
| 手感 | 弦软,指尖友好 | 弦硬,初期较痛 | 弦软,手感轻快 |
| 是否需音箱 | 否 | 否(可加拾音器) | 是 |
| 典型风格 | 古典、弗拉门戈、指弹 | 民谣、流行弹唱、指弹 | 摇滚、布鲁斯、金属、爵士、流行 |
| 入门难度 | 中(乐理/读谱要求高) | 低–中(大横按是坎) | 中(需配置设备) |
| 音量 | 中 | 大 | 可控(耳机静音练习方便) |

## 二、按构造细分

### 原声类(Acoustic,靠箱体共鸣)
- **古典吉他(Classical / Nylon-string)**
- **弗拉门戈吉他(Flamenco)** —— 古典的近亲,更薄更亮、更适合扫击技巧
- **钢弦民谣吉他(Steel-string Acoustic)**,常见箱型:
  - Dreadnought(D 桶):音量大、低音足,弹唱主力
  - Auditorium / OM:均衡,适合指弹与弹唱
  - Concert / Parlor:小箱体,音色集中,便携
  - Jumbo:大箱体,音量与低音强劲
- **十二弦吉他(12-string)** —— 成对弦,声音饱满、有"叮当"般层次
- **电箱琴(Acoustic-electric)** —— 原声琴 + 拾音器,可插电演出

### 电声类(Electric,靠拾音器)
- **实心电吉他(Solid body)** —— Stratocaster、Telecaster、Les Paul 等
- **半空心/空心电吉他(Semi-hollow / Hollow)** —— 爵士、布鲁斯常用,温暖带共鸣
- **低音吉他/贝斯(Bass)** —— 4/5/6 弦,负责低音声部

### 其他家族成员
- **尤克里里(Ukulele)** —— 4 弦小乐器,易上手,适合启蒙
- **共鸣器吉他(Resonator / Dobro)** —— 金属共鸣盘,蓝草/布鲁斯滑棒常用
- **古典变体**:7 弦、巴洛克吉他等
- **现代扩展**:7 弦、8 弦电吉他(金属常用,音域更低)、无头琴等

## 三、怎么选第一把琴(实用建议)

1. **先想清楚你想弹什么风格**——这是最重要的决定因素(见 README 表格)。
2. **手指怕痛 / 小孩** → 尼龙弦古典或尤克里里更友好。
3. **预算有限但想认真学** → 选可靠品牌的入门级,别买玩具琴(玩具琴音准差、手感差,会打击信心)。
4. **住公寓怕扰民** → 电吉他可插耳机静音练习,是优势。
5. **能去琴行就去试手感**:琴颈宽窄、琴体大小要适合你的身材和手。

> 没有"最好的吉他类型",只有"最适合你当下目标的吉他"。很多人最终会拥有不止一把。

---

## 四、不同类型之间能互通吗?

能,而且互相促进:
- 古典吉他练出的右手手指独立性,对指弹民谣极有帮助。
- 民谣练出的和弦与节奏感,转电吉他很快上手。
- 乐理、节奏、听力是**所有类型通用**的底层能力。

所以无论从哪把琴开始,打好基础都不会浪费。
