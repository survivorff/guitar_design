# 🎵 音名与音程

这是所有乐理的起点。理解这一篇,后面的音阶、和弦都是水到渠成。

---

## 一、12 个音(十二平均律)

西方音乐把一个八度分成 **12 个等距的半音**。音名循环如下:

```
A  A#/Bb  B  C  C#/Db  D  D#/Eb  E  F  F#/Gb  G  G#/Ab  (回到 A)
```

- **七个基本音名**:A B C D E F G(对应 do-re-mi 的固定唱名见下)。
- **# (sharp 升号)**:升高半音。**b (flat 降号)**:降低半音。
- 同一个音可有两个名字(如 C# = Db),叫**等音(enharmonic)**。

> 唱名对照(C 大调):C=do, D=re, E=mi, F=fa, G=sol, A=la, B=si/ti。

## 二、半音与全音(最重要的两个概念)

- **半音(Half step / Semitone)**:相邻两个音,在吉他上 = **相邻一品**。
- **全音(Whole step / Tone)**:两个半音,在吉他上 = **隔一品(两品)**。

**关键例外**:基本音名之间**不都是全音**!
```
C →(全)→ D →(全)→ E →(半)→ F →(全)→ G →(全)→ A →(全)→ B →(半)→ C
```
- **E→F 和 B→C 之间只有半音**(它们之间没有黑键/升降音)。
- 记住这两个"天然半音"对理解音阶至关重要。

## 三、在吉他上看半音/全音

- 沿**同一根弦**,每移动**一品 = 半音**,两品 = 全音。
- 例:6 弦空弦 E → 1 品 F(半音)→ 3 品 G(再全音)。
- 这就是为什么吉他是学乐理的好工具:几何关系非常直观。

## 四、音程(Interval)

音程 = 两个音之间的距离。它是和弦、音阶、和声的"砖块"。

### 按"度数"命名
数两个音名之间包含几个音名(含首尾):
- C 到 C = 1 度(同度/unison)
- C 到 D = 2 度
- C 到 E = 3 度
- C 到 F = 4 度
- C 到 G = 5 度
- C 到 A = 6 度
- C 到 B = 7 度
- C 到高 C = 8 度(八度/octave)

### 加上"性质"(大/小/纯/增/减)
同样是"3 度",还分大小,取决于具体半音数:

| 音程 | 半音数 | 例子(从 C 起) | 听感 |
|------|--------|------------------|------|
| 纯一度 | 0 | C–C | 同音 |
| 小二度 | 1 | C–Db | 紧张、刺耳 |
| 大二度 | 2 | C–D | —— |
| 小三度 | 3 | C–Eb | **忧郁(小调色彩)** |
| 大三度 | 4 | C–E | **明亮(大调色彩)** |
| 纯四度 | 5 | C–F | 稳定 |
| 增四度/减五度(三全音) | 6 | C–F#/Gb | 极度紧张("魔鬼音程") |
| 纯五度 | 7 | C–G | **空旷稳定(强力和弦核心)** |
| 小六度 | 8 | C–Ab | —— |
| 大六度 | 9 | C–A | 甜美 |
| 小七度 | 10 | C–Bb | 属七色彩、布鲁斯味 |
| 大七度 | 11 | C–B | 柔和、爵士味 |
| 纯八度 | 12 | C–高C | 同音高八度 |

> 重点先记住:**大三度(4 半音)= 明亮**,**小三度(3 半音)= 忧郁**。这是大小和弦/调的根本区别。

## 五、为什么音程这么重要

- **和弦**由音程叠出来:大三和弦 = 根音 + 大三度 + 纯五度。
- **音阶**是一串特定音程排列。
- **即兴和旋律**好不好听,本质是音程关系。
- 训练耳朵识别音程(听一个音程能说出是大三还是纯五),是练耳的核心。

---

## 在吉他上练音程(直观技巧)

- **纯五度**:同一指型,如 6 弦某品 + 5 弦高两品(强力和弦的形状)。
- **八度**:6 弦某品 + 4 弦高两品(相隔一弦、高两品的经典八度指型)。
- 在琴上弹出每种音程,**用耳朵记住它的"味道"**。
