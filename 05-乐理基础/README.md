# 05 · 乐理基础

乐理是音乐的"语言规则"。懂了它,你才能理解和弦为什么这样搭、即兴该用哪些音、
怎么把脑子里的旋律弹出来。**乐理不是枷锁,是让你更自由的地图。**

## 学习建议

- **理论 + 琴上验证**:学一个概念,马上在吉他上弹出来听。光看不弹等于没学。
- **不用一次学完**:配合技巧和曲子,需要时回来查。
- **耳朵是终点**:理论的目的是让你"听得懂、弹得出",不是背术语。

## 乐理之于各阶段

| 阶段 | 该掌握的乐理 |
|------|--------------|
| 入门 | 音名、节拍、和弦图 |
| 进阶 | 大小调音阶、三/七和弦、调内级数、常见进行 |
| 精通 | 调式、ii-V-I、副属、转调、和声功能 |
| 大师 | 扩展/变化和弦、再和声化、对位 |
