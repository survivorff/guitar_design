# 08 · 精通阶段(Advanced)

到这个阶段,技术和乐理都已成型。精通的标志是:**把碎片整合成体系,能在多种风格里
自如表达,并开始拥有"音乐判断力"**——知道在什么场合该弹什么。

## 本模块内容

- [全指板掌握.md](./全指板掌握.md) —— CAGED 系统、音阶连接、指板可视化
- [即兴入门.md](./即兴入门.md) —— 如何在伴奏上"说话"
- [多风格巡礼.md](./多风格巡礼.md) —— 布鲁斯/摇滚/爵士/古典/民谣的语汇
- [进阶和声.md](./进阶和声.md) —— 副属、转调、再和声化入门
- [扒谱与听力.md](./扒谱与听力.md) —— 用耳朵直接学音乐

## 精通阶段的核心转变

| 之前 | 现在 |
|------|------|
| 记指型/盒子 | 理解每个音的"角色" |
| 照谱弹 | 用耳朵和理论自主选择 |
| 弹会一首歌 | 理解这首歌的语言并能改编 |
| 学技巧 | 用技巧服务表达 |

## 里程碑 ✅

- [ ] 指板任意位置都能即兴,不局限于一个盒子
- [ ] 能跟陌生的和弦进行做出有逻辑的即兴
- [ ] 能演奏至少 3 种风格的代表曲目
- [ ] 能用耳朵扒下中等难度的歌(和弦+旋律)
- [ ] 能为一段旋律配上合理的和弦

> 这个阶段没有"速成",靠的是大量演奏、聆听、思考的积累。享受这个逐渐"开窍"的过程。
