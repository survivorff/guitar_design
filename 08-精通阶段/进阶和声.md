# 🎹 进阶和声(Advanced Harmony)

在基础和声进行(`05/和声进行.md`)之上,这一篇介绍让和声更丰富、更有张力的工具:
副属和弦、转调、借用和弦、再和声化的入门概念。

---

## 一、副属和弦(Secondary Dominants)

回顾:V→I 是最强的解决。副属和弦的思路是:**临时把任何调内和弦当成"主和弦",
给它配一个自己的属和弦(V),制造额外的推动力。**

- 记号:**V/x**,读作"x 的五级"。
- 例(C 调):想让进行更"推"地走向 Dm(ii),可在它前面加 **A7**(A7 是 Dm 的属和弦,即 V/ii)。
  - `C - A7 - Dm - G7 - C` 比 `C - Dm - G7 - C` 更有牵引力。
- 最常见:**V/V**(C 调里的 D7→G),"二级变属"。
- 副属和弦常引入**调外音**,这正是它制造新鲜色彩的原因。

## 二、借用和弦(Modal Interchange / Borrowed Chords)

从**同主音的其他调式**借和弦来用,增添色彩:
- C 大调里借用 C 小调的和弦,最常见的是 **bVII(Bb)、iv(Fm)、bVI(Ab)**。
- 例:`C - Fm - C`,那个借来的 **Fm(小四级)** 有非常动人的"忧伤回望"色彩(无数流行歌用)。
- `C - Bb - F - C`(借 bVII)有摇滚/复古味。

## 三、转调(Modulation)

从一个调平滑过渡到另一个调,让音乐"上一个台阶"或转换情绪。

常见手法:
- **共同和弦转调**:找一个两调都有的和弦作"桥",经它过渡。
- **属和弦牵引**:用目标调的 V 把听众"拉"进新调。
- **直接转调(直上)**:副歌整体升一个全音/半音,流行歌常见的"情绪升级"。
- **等音转调**:利用减七、增和弦的多义性巧妙转向远关系调。

## 四、再和声化(Reharmonization)入门

同一段旋律,**换一套和弦**来配,改变它的色彩。这是爵士和编曲的高级玩法。

常用技巧:
- **用七和弦/扩展和弦替换三和弦**(C → Cmaj7 → Cmaj9)。
- **三全音替代(tritone sub)**:用降二级属七替换 V7(G7 → Db7),爵士标志手法。
- **加入 ii-V**:把一个目标和弦前面插入它的 ii-V,增加流动。
- **经过减和弦**:在两个和弦间插入减七和弦平滑过渡(如 C–C#dim–Dm)。

## 五、扩展与变化和弦(回顾+深化)

- **扩展**:9、11、13 和弦,增加色彩层次(爵士、放克、R&B、neo-soul)。
- **变化属和弦**:7b9、7#9、7#5、7b5(alt),在解决前制造最大张力。
- **sus 和弦**:sus2/sus4 的悬而未决,以及 sus→解决的运用。

## 六、和声听觉训练

理论要变成"听得出"才有用:
- 听一段进行,试着说出它用了副属/借用/转调没有。
- 跟唱根音线条(bass line),它常揭示和声走向。
- 扒喜欢的歌的和声,分析它"为什么好听"。

## 实践:把一个普通进行"升级"

```
原始:   C  -  Am  -  F  -  G
升级思路:
  C  -  A7  -  Dm  -  G7        (用 A7 副属牵引到 Dm)
  Cmaj7 - Am7 - Fmaj7 - G7sus-G7  (加七和弦/挂留增加色彩)
  C  -  Eb  -  F  -  G          (借用 bIII 增加摇滚味)
```
在琴上弹这几个版本,听它们情绪的差异——这就是和声的魔力。
