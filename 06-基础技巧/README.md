# 06 · 基础技巧

这个模块把入门阶段的手上功夫系统化、精细化。目标是让你的双手"听话"、
节奏稳定、音色干净,为进阶技巧打好地基。

## 本模块内容

- [右手:拨弦与扫弦.md](./右手-拨弦与扫弦.md) —— 拨片技巧、交替拨弦、扫弦型
- [左手:按弦与爬格子.md](./左手-按弦与爬格子.md) —— 手指独立、力量、灵活性训练
- [扫弦节奏型大全.md](./扫弦节奏型大全.md) —— 常用扫弦型与切音、闷音
- [大横按.md](./大横按.md) —— 攻克 F 和 B,通往封闭和弦
- [基础指弹.md](./基础指弹.md) —— 分解和弦、Travis picking
- [节奏吉他与强力和弦.md](./节奏吉他与强力和弦.md) —— 强力和弦、律动、乐队中的角色

## 这个阶段的核心目标

- 右手扫弦/拨弦稳定、有律动
- 左手手指独立、灵活、有力,按弦干净
- 能弹响大横按(F)
- 掌握基础指弹模式
- 一切都建立在**节拍器**和**放松**之上

## 练习优先级建议

每次练习从最弱的一项开始(精力最好时攻坚)。基础技巧值得长期反复打磨——
即使到了精通阶段,热身和基本功练习依然每天都要做。
