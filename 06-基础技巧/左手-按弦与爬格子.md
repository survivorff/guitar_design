# ✋ 左手:按弦与爬格子

左手负责音高的准确和切换的流畅。这一篇是关于手指**独立性、力量、灵活性**的
系统训练,这些是一切技巧的物理基础。

---

## 一、按弦基本功(复习+精化)

- **指尖垂直**按弦,按在**靠品丝的前方**(不是品格中间,更不是品丝上)。
- 用**刚好按响**的最小力气——长期追求"省力"。
- 拇指在琴颈背面中央,作为支点;手指自然弯曲呈拱形。
- 手指尽量**贴近指板**(抬太高浪费时间和力气)。

## 二、爬格子(Finger Exercises / "1-2-3-4")

最经典的手指独立性训练,也是绝佳热身。

### 基础 1234
每根手指对应一品,逐弦推进:
```
e|-------------------1-2-3-4-|
B|-----------1-2-3-4---------|
G|---1-2-3-4-----------------|
... 从 6 弦到 1 弦,再反向回来
E|-1-2-3-4-------------------|
 食中无小  (1=食 2=中 3=无名 4=小指)
```

### 要点
- **一个手指一品**,按下后**尽量不抬起**(留在弦上,直到必须移动)。
- 跟**节拍器**,慢速求每个音清晰、均匀、不打品。
- 关注**最弱的无名指和小指**的独立性。
- 速度不是目标,**干净均匀**才是。速度是干净的副产品。

### 变体(增加难度与全面性)
- 换指序:1-3-2-4、1-4-2-3、4-3-2-1 等(共 24 种排列,练手指的各种组合)。
- 横向移动:每组在不同品位重复(跨把位)。
- 跨弦练习:在不相邻的弦间跳跃。

## 三、手指独立性专项

- **保留指(finger independence)**:按住某指不动,其他指做动作。
- **蜘蛛爬(spider)**:手指在相邻弦上交错移动,锻炼协调。
```
e|-----------------|
B|-----------------|
G|--2-----4--------|
D|-----3-----5-----|   (体会手指交错独立)
A|-----------------|
E|-----------------|
```

## 四、力量与耐力

- 力量靠**正确按弦的日积月累**自然增长,不要靠蛮劲死掐(易受伤)。
- 横按(barre)是力量的考验,见 `大横按.md`。
- 感到疲劳/酸痛就**休息**,别硬撑。手指肌腱受伤恢复期很长。

## 五、灵活性与伸展

- 练习前轻轻活动手指、手腕(但不要过度拉伸冷手指)。
- 大跨度指法(stretch)循序渐进,从小跨度逐步加大,绝不强拉。

## 六、左手闷音(Muting)

- 不弹的弦要**闷掉**,避免杂音。
- 左手指腹可以轻搭在不需要发声的弦上消音(尤其弹单音和强力和弦时)。
- 这是让演奏"干净"的隐形功夫,常被忽略却极重要。

---

## 热身惯例(建议每次练习开头 5 分钟)

1. 慢速 1234 爬格子(顺+逆),上下行各一遍。
2. 一条音阶慢速过一遍。
3. 一个换指变体(如 1-3-2-4)。
4. 全程跟节拍器,只在"完全弹对"的速度,不求快。
