# 03 · 装备与配置

工欲善其事,必先利其器。但请记住:**好装备帮你更舒服地练,但不能替代练习。**
这个模块帮你搞清楚需要什么、不需要什么,以及如何保养。

## 新手最小装备清单

不必一次买齐,这是"开始练"所需的最少东西:

- ✅ 一把手感正常、音准准的吉他(最重要)
- ✅ 调音器(夹式或手机 App)
- ✅ 节拍器(手机 App 即可)
- ✅ 几片拨片(如果弹民谣/电吉他)
- ✅ (电吉他)耳机 + 综合效果器或声卡

可选但有用:备用弦、卷弦器、擦琴布、琴架/琴包、变调夹(capo)。
