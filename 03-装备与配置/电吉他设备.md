# 🎛️ 电吉他设备

电吉他本身只是信号源,**音色的一大半来自后端设备**。这一篇帮你理清需要什么,
以及如何在家安静地练出好音色。

---

## 信号链回顾

```
吉他 → 效果器 → 音箱 → 喇叭 → 声音
              (或)
吉他 → 综合效果器 / 声卡 → 耳机 / 监听音箱
```

---

## 一、音箱(Amplifier)

音箱不只是放大,它**塑造音色**(尤其电子管音箱的失真和动态)。

| 类型 | 特点 | 适合 |
|------|------|------|
| 电子管(Tube) | 音色温暖、动态好、失真自然 | 追求音色的进阶玩家;贵、重、需大音量出好声 |
| 晶体管(Solid-state) | 便宜、可靠、轻 | 练习、预算有限 |
| 数字建模(Modeling) | 一台模拟多种经典音箱+效果,带耳机口 | **新手在家练习的首选** |

> 新手强烈推荐**小型建模音箱**或**综合效果器+耳机**:能静音练习、内置多种音色、价格友好。

## 二、效果器(Effects)

### 主要类别
- **增益类**:Overdrive(过载)、Distortion(失真)、Fuzz —— 摇滚金属的核心。
- **调制类**:Chorus(合唱)、Flanger(镶边)、Phaser(相位)。
- **时间类**:Delay(延迟)、Reverb(混响)—— 制造空间感。
- **滤波/动态**:Wah(哇音)、Compressor(压缩)、EQ(均衡)。

### 形态
- **单块(Stompbox)**:一个效果一块,自由组合成"效果板(pedalboard)",玩法丰富但成本累积。
- **综合效果器(Multi-effects)**:一台机器集成大量效果与音箱模拟,性价比高,**适合新手**。
- **软件(Amp Sim / Plugin)**:电脑里运行,配声卡即可,在家录音/练习极方便(如各类 amp sim)。

## 三、在家安静练习方案(公寓友好)

这是电吉他相对原声琴的一大优势——**可以完全静音练习**:

**方案 A:综合效果器 + 耳机**
```
吉他 → 综合效果器(带耳机口) → 耳机
```
最简单,一台搞定,带各种音色和节拍器、鼓机。

**方案 B:声卡 + 电脑 + amp sim + 耳机**
```
吉他 → 音频声卡(audio interface) → 电脑(amp sim 软件) → 耳机
```
适合想顺便录音、做编曲的人,扩展性最强。

**方案 C:带耳机口的小建模音箱**
直接插耳机,即开即练。

## 四、连接线材

- **吉他线(1/4" / 6.35mm)**:连接吉他到设备,选屏蔽好的,劣质线会有杂音。
- 注意接头牢固,避免接触不良导致的"滋滋"声。

## 五、新手设备建议(性价比路线)

1. 一把手感正常的入门电吉他。
2. 一台**综合效果器(带耳机口和鼓机/节拍器)** 或 **声卡 + 免费/廉价 amp sim**。
3. 一副封闭式耳机。
4. 一根质量过关的吉他线。

这套下来就能在任何时间安静地练习,并获得多种专业音色,无需先买大音箱。
