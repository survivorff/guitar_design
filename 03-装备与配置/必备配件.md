# 🧰 必备配件

下面按"必备 → 强烈推荐 → 可选"分级。新手不用一次买齐。

---

## 必备

### 调音器(Tuner)
- **夹式调音器**:夹在琴头,靠振动测音,嘈杂环境也能用,推荐新手。
- **手机 App**:GuitarTuna 等,免费够用。
- **踏板/插线调音器**:电吉他演出用。
> 每次弹之前都要调音。音不准,练再多耳朵都被带歪。

### 节拍器(Metronome)
- 手机 App 即可(很多调音器 App 自带)。
- 练节奏、练速度、练稳定度的核心工具,几乎每次练习都该用。

### 拨片(Pick / Plectrum)(弹民谣/电吉他)
- 厚度(单位 mm)影响手感与音色:
  - **薄(< 0.6mm)**:适合扫弦,声音清脆、易控制力度,新手扫弦友好。
  - **中(0.6–0.8mm)**:扫弦/单音通吃,百搭。
  - **厚(> 0.8mm)**:适合单音/solo、精准拨弦,音色饱满。
- 便宜易丢,多买几片不同厚度试。

## 强烈推荐

### 变调夹(Capo)
- 夹在某品,整体升高调,方便变调、配合人声音域。
- 弹唱几乎必备。

### 备用弦
- 弦会断、会老化。常备一套(电吉他/钢弦尤其)。

### 卷弦器(String winder)
- 换弦时快速转动弦钮,省时省力(很多带断弦钉拔取功能)。

### 擦琴布
- 弹完擦掉弦和琴身上的汗渍油脂,延长弦寿命、保持琴况。

## 可选(按需)

| 配件 | 用途 |
|------|------|
| 背带(Strap) | 站立演奏必备;坐着也可辅助稳定 |
| 琴包 / 琴盒 | 保护与携带;硬盒保护更好 |
| 琴架 / 挂墙架 | 顺手取放,提高练习频率(琴放在看得见的地方更容易拿起来练) |
| 脚凳 / 支撑垫 | 古典吉他坐姿用 |
| 滑棒(Slide) | 滑棒演奏(布鲁斯/乡村) |
| 指套 / 拇指套 | 指弹时增强音量与音色 |
| 湿度计 / 加湿器 | 干燥地区保护原声琴(见保养篇) |
| 弦高尺 / 调试工具 | 自己做基础调试 |

---

## 关于练习用录音

不需要专门买设备:**手机录音**就能极大帮助你进步。
弹一段录下来回听,你会立刻发现节奏不稳、换和弦卡顿等自己弹时察觉不到的问题。
